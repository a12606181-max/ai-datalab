# Deploy

This project is prepared for GitHub + Render auto-deploy.

## 1. Create a GitHub repository

Create a new repository, for example `ai-datalab`, under your GitHub account.

Then connect the local project:

```bash
git remote add origin https://github.com/<your-user>/ai-datalab.git
git add .
git commit -m "Prepare production deploy"
git push -u origin master
```

If you prefer `main` instead of `master`, rename the branch before the first push:

```bash
git branch -M main
git push -u origin main
```

## 2. Create a Render web service

1. In Render, choose `New +` -> `Blueprint`.
2. Select the GitHub repository.
3. Render will read `render.yaml`.
4. Keep the persistent disk enabled at `/var/data`.
5. Add `OPENAI_API_KEY` only if you want the real AI mentor.

## 3. What happens automatically

- Every push to GitHub triggers a new Render deploy.
- Render builds the Next.js app.
- On start, Prisma runs `migrate deploy`.
- On the first deploy only, Render runs `npm run db:seed`.
- The SQLite database is stored on the persistent disk.

## 4. Required environment values

Configured automatically by `render.yaml`:

- `DATABASE_URL=file:/var/data/ai-datalab.db`
- `AUTH_SECRET` generated by Render
- `OPENAI_MODEL=gpt-5.2`

Optional:

- `OPENAI_API_KEY`
