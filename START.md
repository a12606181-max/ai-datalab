# AI DataLab: запуск проекта

Ниже инструкция, по которой можно запустить проект с нуля и потом уверенно повторять запуск самостоятельно.

## 1. Что нужно заранее

- Установленный `Node.js` версии `20` или новее.
- `npm` обычно идет вместе с Node.js.
- Терминал PowerShell или терминал внутри IDE.

Проверка:

```powershell
node -v
npm -v
```

## 2. Открыть проект

Перейдите в папку проекта:

```powershell
cd "C:\Users\Пользователь\Documents\ai-datalab"
```

## 3. Установить зависимости

Если запускаете проект впервые:

```powershell
npm install
```

## 4. Проверить `.env`

Минимально в файле `.env` должны быть такие значения:

```env
DATABASE_URL="file:C:/Users/Public/ai-datalab/dev.db"
AUTH_SECRET="replace-with-a-long-random-secret"
OPENAI_API_KEY=""
OPENAI_MODEL="gpt-5.2"
```

Что важно:

- `DATABASE_URL` лучше оставить как есть, особенно на Windows.
- `AUTH_SECRET` замените на свою длинную случайную строку.
- `OPENAI_API_KEY` можно пока оставить пустым. Тогда встроенный наставник будет работать в локальном режиме без внешнего API.

Пример секрета:

```env
AUTH_SECRET="ai-datalab-super-secret-key-2026-local"
```

## 5. Создать структуру базы данных

Выполните:

```powershell
npm run db:push
```

Команда создаст или обновит структуру SQLite-базы по текущей Prisma-схеме.

## 6. Заполнить проект демо-данными

Выполните:

```powershell
npm run db:seed
```

После этого появятся:

- демо-курсы
- уроки
- лабораторные
- датасеты
- демо-пользователи

## 7. Запустить проект

Выполните:

```powershell
npm run dev
```

После запуска откройте в браузере:

```text
http://localhost:3000
```

## 8. Как войти в систему

Демо-аккаунты:

- Студент: `student@aidatalab.ru` / `Student123`
- Преподаватель: `teacher@aidatalab.ru` / `Teacher123`

Либо можно зарегистрировать нового пользователя вручную.

## 9. Что проверить после запуска

Если проект запустился правильно, должно работать следующее:

- открывается главная страница
- работают страницы `login` и `register`
- после входа открывается `dashboard`
- доступны курсы, уроки и лабораторные
- у преподавателя доступен раздел `/teacher`
- скачиваются датасеты
- проект проходит production-сборку

## 10. Полезные команды

Запуск разработки:

```powershell
npm run dev
```

Проверка проекта перед показом:

```powershell
npm run check
```

Открыть Prisma Studio:

```powershell
npm run db:studio
```

## 11. Как переинициализировать базу

Если хотите заново пересобрать учебные данные:

1. Остановите dev-сервер.
2. Выполните:

```powershell
npm run db:push
npm run db:seed
```

## 12. Частые проблемы

### Prisma ругается на Windows

Не меняйте без необходимости:

```env
DATABASE_URL="file:C:/Users/Public/ai-datalab/dev.db"
```

Эта база вынесена в ASCII-путь специально для Windows.

### Сайт не открывается

Проверьте:

- запущена ли команда `npm run dev`
- не занят ли порт `3000`
- нет ли ошибки в терминале

### Не удается войти

Сначала выполните:

```powershell
npm run db:seed
```

Потом используйте демо-аккаунты из пункта 8.

### ИИ-наставник не отвечает через настоящую нейросеть

Это нормально, если пустой `OPENAI_API_KEY`.

Без ключа наставник работает во встроенном локальном режиме.

## 13. Как запускать проект в следующий раз

Если зависимости уже установлены, а база уже создана, обычно достаточно:

```powershell
cd "C:\Users\Пользователь\Documents\ai-datalab"
npm run dev
```

Потом открыть:

```text
http://localhost:3000
```
