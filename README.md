# AI DataLab

AI DataLab: интеллектуальная образовательная платформа по аналитике данных и искусственному интеллекту.

Это конкурсная LMS-платформа в тёмной AI/SaaS-стилистике. Проект предназначен для обучения школьников, студентов колледжей и вузов аналитике данных и искусственному интеллекту через онлайн-курсы, подробные уроки, расширенные мини-тесты, лабораторные работы, учебные датасеты, автоматическую проверку решений и ИИ-наставника.

## Цель проекта

Создать рабочую образовательную онлайн-платформу, которую можно показать экспертам конкурса и использовать как основу для внедрения в образовательной организации.

Платформа должна:

- обучать ИТ-направлениям в онлайн-формате;
- давать практические кейсы по аналитике данных и ИИ;
- показывать прогресс и аналитику обучения;
- поддерживать роли студента и преподавателя;
- запускаться локально без обязательных внешних API-ключей.

## Архитектура

Проект реализован как full-stack приложение на Next.js:

- `App Router` отвечает за страницы платформы и layout.
- `Server Actions` обрабатывают регистрацию, вход, отправку лабораторных, завершение уроков, сообщения наставнику и действия преподавателя.
- `Prisma + SQLite` хранят пользователей, курсы, уроки, тесты, лабораторные, сабмиты, прогресс и сообщения ИИ-наставника.
- `Middleware` защищает закрытые маршруты и ограничивает доступ к панели преподавателя для роли `TEACHER`.
- `Recharts` используются для аналитических графиков и круговых диаграмм.
- `Tailwind CSS` и собственные glassmorphism-компоненты формируют единый тёмный AI/SaaS-интерфейс.

## Установка и запуск

### Основной сценарий

```bash
npm install
npx prisma db push
npx prisma db seed
npm run dev
```

После запуска приложение будет доступно по адресу:

```bash
http://localhost:3000
```

### Важно для Windows

В проекте SQLite настроен через `.env` на ASCII-путь:

```env
DATABASE_URL="file:C:/Users/Public/ai-datalab/dev.db"
```

Это сделано для стабильной работы Prisma на Windows-конфигурациях, где путь к проекту может содержать кириллицу.

Если нужен именно сценарий с миграциями, можно попробовать:

```bash
npx prisma migrate dev
```

Но на некоторых Windows-конфигурациях Prisma стабильнее использовать `npx prisma db push`.

## Как подключить реальный ИИ

В проект уже добавлена готовность к реальному OpenAI API для страницы `ИИ-наставник`.

Нужно:

1. Добавить ключ в `.env`:

```env
OPENAI_API_KEY="ваш_ключ"
OPENAI_MODEL="gpt-5.2"
```

2. Перезапустить:

```bash
npm run dev
```

После этого ИИ-наставник начнёт отвечать через OpenAI API. Если ключ не задан, система автоматически использует локальный rule-based режим, поэтому проект по-прежнему запускается без внешних сервисов.

## Логика автопроверки лабораторных

Система использует локальную rule-based проверку:

- если ответ длиннее 100 символов, начисляются дополнительные баллы;
- ключевые слова `график`, `вывод`, `данные`, `модель`, `точность`, `признаки` повышают оценку;
- итог ограничен 100 баллами;
- формируется feedback:
  - сильные стороны;
  - что улучшить;
  - рекомендация ИИ-наставника.
